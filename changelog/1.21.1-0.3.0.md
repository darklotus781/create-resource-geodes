## [0.3.0]
- Removed Create mod dependency
- Removed AE2 mod dependency
- All Catalysts are 100% data driven and modpack author defined
- Maintained support for legacy catalysts via catalysts_bootstrap.json and optional datapacks / resource packs.

## UPGRADE WARNING
If you are upgrading, your catalysts will NOT work...  
You need to download the resource pack / data pack files and update to fit your needs.

- AE2 Skystone Catalyst + Worldgen Geode
    - [Data Pack](https://lithiumcraft.com/files/createresourcegeodes/datapack/ae2.zip) / [Resource Pack](https://lithiumcraft.com/files/createresourcegeodes/resourcepack/ae2.zip)
- Create Ore Stone (Asurine, Crimsite, Ochrum, Veridium) Catalysts + Worldgen Geodes
    - [Data Pack](https://lithiumcraft.com/files/createresourcegeodes/datapack/create.zip) / [Resource Pack](https://lithiumcraft.com/files/createresourcegeodes/resourcepack/create.zip)
- Diamond Catalyst, Frozen Catalyst, Radioactive Catalyst + Worldgen Geodes
    - [Data Pack](https://lithiumcraft.com/files/createresourcegeodes/datapack/custom.zip) / [Resource Pack](https://lithiumcraft.com/files/createresourcegeodes/resourcepack/custom.zip)

We have a very helpful [Discord](https://discord.gg/XH7zCjgUHb) if you need a hand with upgrading!
